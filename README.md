### **About**
It is a Base Station Controller. Can control to call wake up mode or sleep mode by using CLI.

### **How to use**
You can download by [Release](https://github.com/Keeze392/base_stations_controller/releases/tag/0.1.3).

To run: \
`./base_station_controller wake` or write "sleep" instead "wake".

Enjoy.

### **Explain the Options**
- `wake` Wake the Base Station up.
- `sleep` Put the Base Station in sleep mode
